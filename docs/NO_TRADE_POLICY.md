# FX NO_TRADE Policy

Return NO_TRADE when capital cannot be justified.

Examples:

- edge too weak
- expected return below expected costs
- spread too large
- liquidity too low
- regime unknown
- major event too close
- stale data
- conflicting providers
- corrupted data
- excessive model disagreement
- historical sample too small
- strategy degraded
- portfolio concentration too high
- risk limit reached
- broker mismatch
- unreconciled position
- system health degraded
- execution cost too high
- stop too wide
- reward too small
- opposing structure too close
- slippage estimate unstable
- kill switch active
- invalid security state
- execution parity unacceptable
