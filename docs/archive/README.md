# Archived project material

Files below this directory are retained for provenance and historical reference.
They are not runtime dependencies, active implementation instructions, or the
current source of truth.

- `legacy_build_material/` contains superseded handoff documents, patch bundles,
  and one-time upgrade scripts.
- `source_material/` contains third-party PDFs and source documents used during
  earlier research.

Current authority remains `AGENTS.md`, `README.md`, the root conversation context,
the trading constitution, risk specification, strategy promotion pipeline, and
the dated QA acceptance report.
